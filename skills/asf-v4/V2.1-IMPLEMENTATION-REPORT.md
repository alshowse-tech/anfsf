## 🚨 问题背景

### SparkPath 项目交付问题

| 问题 | 表象 | 根因 |
|------|------|------|
| **1. UI 风格不统一** | 部分内容无 UI/反复调整 | Visual Design 阈值过低 (0.6) |
| **2. 无直接 UX 生成** | 需二次指令实现二级页面 | 无 User Journey 维度 |

| **5. 自检虚高** | 自评 100%→实际 60% | 无自检准确率检测 |

## ✅ V2.1 补丁内容

### 1. 评分维度增强 (v21-scoring.ts)

#### 新增维度
| 维度 | 权重 | 阈值 | 针对问题 |
|------|------|------|---------|
| **User Journey** | 25% | 0.85 | 问题 2, 4 |
| **UI Consistency** | 20% | 0.85 | 问题 1 |
| **Real Data** | 15% | 0.80 | 问题 3 |

#### 权重调整
| 维度 | 原权重 | 新权重 | 说明 |
|------|-------|-------|------|
| Visual Design | 20% | 20% | 阈值 0.6→0.85 |
| Code Quality | 20% | 10% | 降低避免掩盖功能缺失 |
| Product Depth | 30% | 15% | 降低聚焦深度而非广度 |
| Functionality | 30% | 15% | 降低合并到 User Journey |

#### 演示级标准
```typescript
const DEMO_READY_THRESHOLDS = {
  overallScore: 0.85,
  userJourney: 0.85,
  uiConsistency: 0.85,
  realData: 0.80,
  functionality: 0.80
};
```

#### 自检准确率检测
```typescript
// 方差越大，自检准确率越低
const variance = Math.abs(metrics.userJourney - metrics.codeQuality);
const selfCheckAccuracy = Math.max(0, 1 - variance * 2);
```

### 2. Karpathy 双层架构集成

#### Layer A: Inline Guard (karpathy-inline-guard.ts)

**延迟目标**: <50ms

| 检查项 | 阈值 | 检测方式 |
|--------|------|---------|
| **Simplicity First** | <3x | 实际行数/最小行数 |
| **Surgical Changes** | <30% | 修改文件数/总文件数 |
| **Goal-Driven Execution** | >80% | E2E 测试覆盖率 |

**Karpathy 原则**:
> "If you write 200 lines and it could be 50, rewrite it."

#### Layer B: External Review (karpathy-external-review.ts)

**延迟**: 2-5 秒

| 审核项 | 检测内容 | Veto 权 |
|--------|---------|--------|
| **Think Before Coding** | 假设确认记录 | ✅ |
| **Goal-Driven Audit** | 用户旅程完整性 | ✅ |

**触发条件**:
- 项目规模 ≥5000 行
- 功能数量 ≥7 个
- 生产环境部署

#### 集成层 (karpathy-integration.ts)

```typescript
// 完整审核流程
const report = await integration.performFullAudit(
  projectId,
  actualLines, minimalLines,    // Simplicity
  touchedFiles, totalFiles,     // Surgical
  coveredTests, totalTests,     // Goal-Driven
  projectLines, featureCount,   // External 触发
  isProduction,
  sessionLog,
  completedFeatures, totalFeatures,
  e2eTestResults
);
```

## 🔧 使用示例

### V2.1 评分引擎
```typescript
import { createV21ScoringEngine } from './harness/v21-scoring';

const engine = createV21ScoringEngine();

const result = engine.calculateScore({
  productDepth: 0.8,
  functionality: 0.7,
  visualDesign: 0.9,
  codeQuality: 0.9,
  userJourney: 0.85,
  uiConsistency: 0.88,
  realData: 0.82
});

console.log(`总分：${result.overallScore.toFixed(2)}`);
console.log(`演示级：${result.demoReady}`);
console.log(`自检准确率：${(result.selfCheckAccuracy * 100).toFixed(1)}%`);
```

### Karpathy 双层架构
```typescript
import { createKarpathyIntegration } from './harness/karpathy-integration';

const integration = createKarpathyIntegration();

// 完整审核流程
const report = await integration.performFullAudit(
  'sparkpath-project',
  500, 100,    // 实际 500 行/最小 100 行 = 5x ✗
  15, 20,      // 修改 15/20 文件 = 75% ✗
  3, 10,       // 测试覆盖 30% ✗

  true,        // 生产环境
  sessionLog,
  6, 10,       // 60% 完成度
  e2eResults
);

if (!report.overallPassed) {
  console.log('部署被 Veto 权阻断');
  console.log('问题:', report.inlineResult.issues);
}
```
