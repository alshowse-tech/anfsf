## 🛡️ 治理门禁设计

### Prompt 缓存配置

```json
{
  "promptCache": {
    "enabled": true,
    "strategy": "adaptive",
    "ttlSeconds": 3600,
    "maxEntries": 1000,
    "costConfig": {
      "cacheRead": 0.0001,
      "cacheWrite": 0.001
    }
  }
}
```

### Provider 路由策略

```json
{
  "providerRouting": {
    "strategy": "cost_optimized",
    "fallbackChain": ["modelstudio", "bailian", "anthropic", "openai"],
    "maxRetries": 3,
    "timeoutMs": 30000
  }
}
```
