## 📊 架构对比

### 当前架构 (传统单体)

```
┌─────────────────────────────────────┐
│         前端 (Vue 3)                 │
├─────────────────────────────────────┤
│         FastAPI (单体)               │
│  ┌─────────────────────────────┐   │

│  └─────────────────────────────┘   │
├─────────────────────────────────────┤
│      PostgreSQL + Redis             │
```

**问题**:
- ❌ 无 Harness 分离
- ❌ 无治理控制
- ❌ 无自我进化
- ❌ 耦合度高

## 🚀 重构步骤

### 步骤 1: 备份当前代码
```bash
git branch backup-pre-anfsf
```

### 步骤 2: 创建 Harness 结构
```
stock-trading-simulator/
├── harness/
│   ├── orchestration/
│   ├── evolution/
│   ├── ui-ux/
│   └── governance/
├── layer8.5/
│   ├── mcp-bus/
│   ├── skills-registry/
│   └── harness-registry/
└── ...
```

### 步骤 3: 迁移代码到 Harness
- 路由逻辑 → Orchestration Harness
- 优化逻辑 → Evolution Harness
- 前端组件 → UI/UX Harness
- 规则检查 → Governance Harness

### 步骤 4: 集成 Layer 8.5
- 配置 MCP 总线
- 注册 Skills
- 注册 Harness

### 步骤 5: 启用自我进化
- 配置 KPI 指标
- 设置 A/B 测试
- 启用自动优化

### 步骤 6: 配置治理规则
- 定义 Veto 规则
- 配置 Policy 检查
- 设置安全护栏

### 步骤 7: 测试验证
- 运行单元测试
- 运行集成测试
- 性能基准测试
