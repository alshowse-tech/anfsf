# SparkPath UI/UX 设计文档 (Apple 风格)

**设计版本**: 1.0  
**设计风格**: Apple 风格 (简洁、优雅、无 AI 味)  
**适用阶段**: 小学/初中/高中

---

## 🎨 设计语言

### 核心理念
> "科技应该隐形，体验应该自然。"

SparkPath 的界面设计遵循 Apple 设计哲学：
- **简洁**: 去除一切不必要的元素
- **优雅**: 每个交互都流畅自然
- **无 AI 味**: 不刻意强调技术，专注于学习体验

## 📱 三阶段界面系统

### 小学阶段 (9-12 岁)

**设计关键词**: 明亮、活泼、友好、游戏化

#### 色彩方案
```css
:root {
  --primary: #FF6B6B;      /* 珊瑚红 - 热情活泼 */
  --secondary: #4ECDC4;    /* 青绿 - 清新自然 */
  --accent: #FFE66D;       /* 明黄 - 快乐阳光 */
  --background: #FFF9F0;   /* 暖白 - 温馨舒适 */
  --surface: #FFFFFF;      /* 纯白 - 干净整洁 */
  --text: #2D3436;         /* 深灰 - 清晰可读 */
  --success: #00B894;      /* 成功绿 */
  --warning: #FDCB6E;      /* 警告黄 */
  --error: #FF7675;        /* 错误红 */
}
```

#### 界面特征
- **圆角**: 20px (大圆角，柔和友好)
- **阴影**: `0 8px 24px rgba(255, 107, 107, 0.2)` (活泼彩色阴影)
- **边框**: 3px 彩色边框
- **图标**: 卡通风格，大眼睛/笑脸
- **动画**: 弹性动画 (spring: mass 0.8, stiffness 400, damping 12)

#### 交互特征
- **按钮尺寸**: 最小 56px 高 (适合小手点击)
- **反馈**: 点击放大 1.05 倍 + 彩色涟漪
- **游戏化**: 徽章/星星/进度条可视化
- **语音**: 可爱童声 TTS

## 🎬 动画规范

### 页面过渡
```css
/* 推入动画 (Push) */
.page-enter {
  transform: translateX(100%);
  opacity: 0;
}
.page-enter-active {
  transform: translateX(0);
  opacity: 1;
  transition: all 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

/* 淡入动画 (Fade) */
.fade-enter {
  opacity: 0;
}
.fade-enter-active {
  opacity: 1;
  transition: opacity 200ms ease-out;
}
```

### 按钮交互
```css
/* 小学阶段 - 弹性按压 */
.btn-elementary:active {
  transform: scale(1.05);
  box-shadow: 0 12px 32px rgba(255, 107, 107, 0.3);
  transition: all 100ms cubic-bezier(0.68, -0.55, 0.265, 1.55);
}

/* 初中阶段 - 轻微反馈 */
.btn-middle:active {
  transform: scale(0.98);
  opacity: 0.9;
  transition: all 150ms ease-out;
}

/* 高中阶段 - 颜色变化 */
.btn-high:active {
  background-color: var(--primary-dark);
  transition: background-color 100ms ease-out;
}
```

### TTS 逐词高亮
```css
/* 平滑滚动跟随 */
.highlight-word {
  transition: background-color 150ms ease, color 150ms ease;
}

.highlight-word.active {
  background-color: var(--primary);
  color: white;
  border-radius: 4px;
  padding: 2px 4px;
}

/* 自动滚动容器 */
.tts-container {
  scroll-behavior: smooth;
}
```

## 📐 响应式布局

### 断点定义
```css
/* 手机竖屏 */
@media (max-width: 414px) {
  --spacing-unit: 12px;
  --font-scale: 0.9;
}

/* 手机横屏 / 小平板 */
@media (min-width: 415px) and (max-width: 768px) {
  --spacing-unit: 16px;
  --font-scale: 1.0;
}

/* 平板 / 桌面 */
@media (min-width: 769px) {
  --spacing-unit: 24px;
  --font-scale: 1.1;
}
```

### 多设备适配
| 设备 | 布局 | 交互 |
|------|------|------|
| **手机** | 单列，底部导航 | 触控优先 |
| **平板** | 双列，侧边导航 | 触控 + 键盘 |
| **桌面** | 三列，完整导航 | 键鼠优先 |

## ♿ 无障碍设计

### 字体大小
- 支持系统字体缩放 (100%-200%)
- 最小可点击区域 44x44pt

### 色彩对比度
- 正文文字：对比度≥4.5:1
- 大标题：对比度≥3:1
- 不依赖颜色传达信息

### 语音支持
- 完整 VoiceOver/TalkBack 支持
- 所有图标有文字标签
- 动态内容实时播报

## 🎯 设计验收标准

| 检查项 | 标准 | 验证方法 |
|--------|------|---------|
| **简洁性** | 每屏≤5 个主要操作 | 设计审查 |
| **流畅度** | 动画 60fps 无卡顿 | 性能测试 |
| **一致性** | 三阶段共享设计语言 | 设计系统审计 |
| **无 AI 味** | 无机器人/科技元素 | 用户测试 |
| **可读性** | 文字对比度≥4.5:1 | 无障碍检测 |
| **可点击** | 最小 44x44pt | 自动化测试 |
