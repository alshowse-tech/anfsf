
#### 3. Knowledge Graph Schema (knowledge-graph-schema.ts)

**功能**:
- ✅ 知识节点完整 Schema
- ✅ Neo4j 图数据库定义
- ✅ 验证流程类型
- ✅ 更新机制配置

**核心 Schema**:
```typescript
interface KnowledgeNode {
  id: string;                    // 唯一 ID
  subject: Subject;              // 科目
  stage: Stage;                  // 学段
  grade: number;                 // 年级

}
```

```
准确率<99% → 回退到知识图谱
准确率≥99% → 发布到内容池
```
