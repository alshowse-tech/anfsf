# SparkPath (贯穿星火)

> **9-18 岁贯穿式 AI 个人学习伙伴**
> 
> 高效掌握知识 + 防止退出 = 短期成绩提升 + 长期自主学习习惯养成

---

## 🎯 产品定位

SparkPath 是专为 9-18 岁学生打造的 AI 个人学习伙伴，贯穿小学、初中、高中三个阶段。

### 核心价值
| 维度 | 目标 | 验证指标 |
|------|------|---------|
| **短期** | 成绩可见提升 | 知识掌握率提升≥30% |
| **长期** | 自主学习习惯养成 | 单次学习≥25 分钟，中断率≤5% |

### 差异化壁垒
1. 🧠 **双引擎动态协同** - 学习加速 (主) + 行为驱动 (辅)
2. 📚 **官方级内容准确性** - 国家课程知识图谱 + AI 动态生成 + 验证闭环
3. 🔄 **全生命周期映射** - 小学→初中→高中自动迁移

## 🚀 快速开始

### 环境要求
- Node.js ≥ 20.0
- npm ≥ 10.0
- Xcode ≥ 15 (iOS 开发)
- Android Studio ≥ 2023.1 (Android 开发)

### 安装
```bash
# 克隆项目
git clone <repo>
cd sparkpath

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env

# 启动开发服务器
npm run dev
```

### 运行
```bash
# 学生端 (iOS)
npm run ios:student

# 学生端 (Android)
npm run android:student

# 家长端
npm run ios:parent

# Web 管理台
npm run web:admin
```

## 📦 核心模块

### Learner Model Engine
实时构建学生知识图谱 + 行为状态，支持跨阶段自动映射。

### 学习加速引擎 (主引擎)
- 知识漏洞精准定位
- 最短学习路径规划
- 方法提炼教学
- 动态难度自适应

### 行为驱动引擎 (辅引擎)
- 退出风险检测
- 三阶段差异化介入策略
- 仅在必要时接管

### Experience Generator
- 实时生成教学内容
- TTS 语音 + 逐词高亮同步
- 三阶段界面风格切换
