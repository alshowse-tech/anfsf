# 初中阶段 UI 原型规范

**版本**: 1.0  
**创建时间**: 2026-04-22  
**目标用户**: 13-15 岁初中生  
**设计风格**: 简洁现代、清爽活力、渐变色彩

---

## 📋 设计概述

### 核心原则

1. **效率优先**: 学习工具化，减少干扰元素
2. **视觉清晰**: 界面简洁，信息层级明确
3. **适度激励**: 成就系统更加理性，注重实际进步
4. **自主学习**: 提供更多自主选择和探索空间
5. **社交适度**: 有限的社交功能，促进良性竞争

### 用户特征

| 特征 | 设计响应 |
|------|---------|
| **自主意识强** | 更多选择权 + 自定义选项 |
| **阅读能力强** | 文字内容更丰富详细 |
| **审美要求高** | 简洁现代的设计风格 |
| **竞争意识** | 排行榜 + 成就系统 |
| **专注力提升** | 减少不必要的动画干扰 |

## 🎨 视觉设计

### 色彩方案

**主色调**: 
- Primary: `#6C63FF` (紫罗兰) - 智慧、创新
- Secondary: `#50E3C2` (蓝绿色) - 清新、科技  
- Accent: `#FF9F43` (活力橙) - 活力、创造

**背景色**:
- 主背景: `#FFFFFF` (纯白)
- 卡片背景: `linear-gradient(180deg, #FFFFFF 0%, #F8F9FA 100%)`
- 强调背景: `#F0F7FF` (淡蓝色)

**文字色**:
- 主文字: `#2D3748` (深灰蓝)
- 辅助文字: `#718096` (中灰)
- 强调文字: `#6C63FF` (紫罗兰)

### 字体系统

```
字体家族: 'Inter', 'Noto Sans SC', 'PingFang SC'
字号:
  - 大标题: 32px (加粗)
  - 主标题: 24px (加粗)  
  - 副标题: 20px (常规)
  - 正文: 16px (常规)
  - 辅助文字: 14px (常规)
  - 按钮: 16px (加粗)
行高: 1.6
```

### 图标风格

- **风格**: 简洁线条图标
- **线条**: 2px 统一线宽
- **颜色**: 使用主色调
- **尺寸**: 20×20px (最小), 32×32px (主要)
- **动画**: 微交互动画 (hover 效果)

## 🔲 核心组件

### 1. 导航栏 (Navbar)

**位置**: 顶部固定  
**高度**: 64px  
**背景**: 白色 + 底部细线分割  
**元素**:

```
[Logo] [首页] [课程] [练习] [排行榜] [个人中心]

Logo: SparkPath 简洁 Logo (32×32px)
菜单项: 图标 + 文字 (20px 图标 + 16px 文字)
当前页: 底部指示条 (2px 高度, Primary 色)
```

**交互**:
- 悬停: 轻微上移 + 颜色变亮
- 点击: 平滑过渡 + 页面切换

### 2. 侧边栏 (Sidebar)

**位置**: 左侧滑出  
**宽度**: 280px  
**背景**: 白色  
**触发**: 顶部汉堡菜单或快捷键

**内容**:
```
- 个人头像 (圆形, 48×48px)
- 用户名 + 班级
- 当前积分: 🌟 2850
- 等级进度: Lv.5 ███████░░░
- 快捷入口: [我的课程] [错题本] [学习报告] [好友]
- 设置: 齿轮图标
```

### 3. 主卡片 (Main Card)

**尺寸**: 响应式 (桌面 280×200px, 移动 260×180px)  
**背景**: 白色  
**圆角**: 12px  
**阴影**: `0 4px 12px rgba(108, 99, 255, 0.1)`

**内容结构**:
```
┌─────────────────┐
│    封面图/图标   │  (80×80px)
├─────────────────┤
│    标题文字      │  (20px 加粗)
│    描述文字      │  (14px 常规)
├─────────────────┤
│   [开始按钮]     │  (44×44px 圆形)
└─────────────────┘
```

**交互**:
- 悬停: 上移 2px + 阴影加深
- 点击: 平滑过渡 + 页面跳转

### 4. 进度条 (Progress Bar)

**高度**: 16px  
**圆角**: 8px  
**填充**: Primary 色渐变 (`#6C63FF → #50E3C2`)  
**装饰**: 右侧显示百分比 + 等级徽章

**显示内容**:
- 左侧: 课程/科目名称
- 右侧: 百分比 (如 "75%")
- 内部: 平滑填充动画

### 5. 成就徽章 (Achievement Badge)

**形状**: 圆角矩形或盾牌形  
**尺寸**: 48×48px  
**背景**: 渐变 + 微光效  
**图标**: 简洁线条风格 (奖杯、星星、火箭等)

**状态**:
- 未获得: 浅灰色 + 锁定图标
- 已获得: 彩色渐变 + 微光效
- 新获得: 缩放动画 + 通知

### 6. 按钮 (Button)

**主要按钮**:
- 尺寸: 44×44px (圆形) 或 100×44px (矩形)
- 背景: Primary 色 (#6C63FF)
- 文字: 白色, 16px, 加粗
- 圆角: 22px (圆形) / 8px (矩形)
- 阴影: `0 2px 8px rgba(108, 99, 255, 0.2)`

**次要按钮**:
- 尺寸: 40×40px
- 背景: 透明
- 边框: 1px Primary 色
- 文字: Primary 色

**交互**:
- 悬停: 颜色变亮 + 轻微上移
- 点击: 压缩动画 + 反馈

## 🎭 交互原型

### 主要交互流程

1. **首页 → 学习计划**
   - 点击课程卡片 → 课程详情页
   - 动画: 卡片上移 + 页面淡入

2. **课程详情 → 继续学习**
   - 点击"继续学习" → 最后学习位置
   - 动画: 按钮颜色变化 + 页面滑入

3. **学习 → 练习**
   - 完成知识点 → 自动进入练习
   - 动画: 进度更新 + 成就检查

4. **练习 → 排行榜**
   - 完成练习 → 更新积分和排名
   - 动画: 数字滚动 + 排名变化

### 动画规范

| 动画类型 | 时长 | 缓动函数 | 触发条件 |
|---------|------|---------|---------|
| **页面切换** | 250ms | ease-out | 导航跳转 |
| **按钮点击** | 120ms | ease | 按钮交互 |
| **卡片悬停** | 150ms | ease-out | 鼠标悬停 |
| **成就获得** | 300ms | ease | 新成就解锁 |
| **进度更新** | 500ms | ease-in-out | 进度变化 |

## ♿ 无障碍设计

### 视觉辅助

- **字体大小**: 最小 16px
- **对比度**: 文字与背景对比度 ≥ 4.5:1
- **信息层级**: 清晰的视觉层次
- **颜色盲友好**: 图标 + 文字双重标识

### 听觉辅助

- **可选语音**: 关键内容可开启语音
- **音效控制**: 音效开关和音量控制
- **通知声音**: 重要通知有声音提示

### 操作辅助

- **点击区域**: 最小 44×44px
- **键盘导航**: 完整 Tab 键支持
- **快捷键**: 常用操作快捷键
- **手势支持**: 触摸设备手势优化

## 📱 响应式设计

### 断点设置

```
手机 (<768px):
  - 单列布局
  - 字体保持 16px
  - 按钮高度 44px
  
平板 (768px-1023px):
  - 双列卡片
  - 字体 16px
  - 按钮高度 44px
  
桌面 (≥1024px):
  - 三列卡片
  - 字体 16px
  - 按钮高度 44px
```

### 触摸优化

- **触摸目标**: 最小 44×44px
- **间距**: 元素间至少 8px 间距
- **手势**: 支持滑动、双击
- **反馈**: 触摸时有视觉反馈
