### P1-T5: TTS 服务选型测试

**负责人**: 后端开发  
**优先级**: P0  
**预计工时**: 3 天  
**截止日期**: 04-25 (周六)

**任务描述**:

**交付物**:
- [ ] `tts-evaluation.md` (TTS 服务评估报告)
- [ ] TTS 服务选型建议
- [ ] 性能测试数据

**候选服务**:
| 服务 | 优势 | 劣势 | 预估延迟 | 成本 |
|------|------|------|---------|------|
| Azure TTS | 音质好，支持中文 | 国内延迟高 | ~250ms | 中 |
| 阿里云 TTS | 国内延迟低 | 音质一般 | ~150ms | 低 |
| 百度 TTS | 免费额度多 | 音质一般 | ~180ms | 低 |
| 科大讯飞 | 音质优秀，教育专用 | 成本高 | ~200ms | 高 |
| 本地 TTS | 无网络延迟 | 音质较差 | ~50ms | 中 |

**测试指标**:
- [ ] 延迟测试 (100 次平均)
- [ ] 音质评分 (1-5 分)
- [ ] 中文发音准确度
- [ ] 并发能力测试
- [ ] 成本核算

**验收标准**:
- [ ] 完成 5 家服务测试
- [ ] 延迟≤200ms
- [ ] 音质≥4 分
- [ ] 成本可控
- [ ] 通过架构师评审

### P1-T6: TTS 同步技术验证

**负责人**: 后端开发  
**优先级**: P0  
**预计工时**: 2 天  
**截止日期**: 04-26 (周日)

**任务描述**:
实现 TTS 与文字逐词高亮同步，确保"眼睛跟着声音走"。

**交付物**:
- [ ] `tts-sync-poc/` (技术验证代码)
- [ ] `tts-sync-test.md` (同步测试报告)
- [ ] Demo 视频

**技术方案**:
```
方案 1: WebSocket 实时同步
  TTS 服务 → WebSocket → 前端接收时间戳 → 高亮对应文字
  延迟：~50ms
  复杂度：中

方案 2: 预生成时间戳
  TTS 生成时同时生成 word_timestamps
  前端按时间戳播放
  延迟：~20ms
  复杂度：低

方案 3: 本地同步
  使用 Web Speech API + 本地计算
  延迟：~10ms
  复杂度：低
```

**测试指标**:
- [ ] 同步延迟≤200ms
- [ ] 高亮准确率≥99%
- [ ] 断点续播支持
- [ ] 倍速播放支持 (0.5x-2.0x)

**验收标准**:
- [ ] POC 代码完成
- [ ] 同步延迟≤200ms
- [ ] Demo 视频录制
- [ ] 通过技术评审
