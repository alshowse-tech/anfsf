## 四、Flowstep 使用指南

### 4.1 快速开始

1. 登录 https://flowstep.ai/
2. 点击"Create New Project"
3. 输入提示词生成 UI

### 4.2 推荐提示词

**小学界面**:
```
Design a learning dashboard for elementary school students (ages 9-12). 
Style: bright, colorful, cartoon-like, playful.
Features: progress bar, achievement badges, course cards, gamified elements.
Colors: orange, yellow, blue, green.
Large buttons, rounded corners, friendly UI.
```

**初中界面**:
```
Design a learning platform for middle school students (ages 13-15).
Style: clean, modern,简洁.
Features: course list, progress tracking, leaderboard, social elements.
Colors: blue, white, gray.
Medium buttons, balanced layout.
```

**高中界面**:
```
Design a learning system for high school students (ages 16-18).
Style: professional, dark mode, focused.
Features: goal planning, detailed analytics, exam prep.
Colors: dark blue, black, accent colors.
Compact layout, information-dense.
```

### 4.3 导出到 Penpot

1. 在 Flowstep 生成设计
2. 点击"Export"
3. 选择"SVG"或"PNG"
4. 导入到 Penpot 作为参考
