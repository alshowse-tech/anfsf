## 三、数据 Schema 定义

### 知识节点结构

```typescript
interface KnowledgeNode {
  // 基本信息
  id: string;                    // 格式：SUBJECT-STAGE-GRADE-NUMBER
  subject: 'math' | 'chinese' | 'english' | ...;
  stage: 'elementary' | 'middle' | 'high';
  grade: number;                 // 1-9
  name: string;                  // 知识点名称
  type: 'concept' | 'method' | 'skill' | 'application';
  
  // 内容详情
  definition: string;            // 核心定义
  methodSteps: string[];         // 方法步骤
  examples: Example[];           // 典型例题
  commonMistakes: string[];      // 易错点
  realWorldApplications: string[]; // 生活应用场景
  
  // 关联关系
  prerequisites: string[];       // 前置知识点 ID
  leadsTo: string[];             // 后续知识点 ID
  
  // 阶段适配
  stageAdaptations: {
    elementary?: StageAdaptation;
    middle?: StageAdaptation;
    high?: StageAdaptation;
  };
  
  // 元数据
  version: string;
  lastUpdated: Date;
  source: '教育部课标' | '人教版' | 'AI 生成';
  accuracy: number;              // 准确率 (0-1)
  reviewStatus: 'pending' | 'approved' | 'rejected';
}
```

### 例题结构

```typescript
interface Example {
  id: string;
  question: string;              // 题目
  solution: string[];            // 解答步骤
  answer: string;                // 答案
  explanation: string;           // 解析
  difficulty: 1 | 2 | 3 | 4 | 5;
  tags: string[];                // 标签
}
```

### 阶段适配结构

```typescript
interface StageAdaptation {
  presentationStyle: 'comic' | 'logical' | 'strategic';
  explanationTone: 'playful' | 'neutral' | 'professional';
  exampleContext: 'daily_life' | 'academic' | 'exam_oriented';
  visualAids: string[];
  interactiveElements: string[];
}
```

## 五、数据导入流程

### 流程图

```
数据收集 → 数据清洗 → 格式转换 → 质量验证 → 导入 Neo4j → 验证测试
   ↓           ↓           ↓           ↓           ↓           ↓
课标/教材    去重/标准化  JSON 格式化   准确率检查   批量导入    抽样测试
```

### 详细步骤

#### Step 1: 数据收集

**负责人**: 内容团队  
**工具**: Excel/Notion

**收集模板**:
```excel
| 知识点 ID | 名称 | 定义 | 方法步骤 | 例题 | 易错点 | 来源 |
|----------|------|------|---------|------|--------|------|
| MAT-e5-0001 | 分数乘法 | ... | ... | ... | ... | 人教版 5 年级 |
```

#### Step 2: 数据清洗

**负责人**: 内容团队 + 后端开发  
**工具**: Python 脚本

**清洗规则**:
- [ ] 去除重复知识点
- [ ] 标准化术语
- [ ] 补充缺失字段
- [ ] 验证关联关系

#### Step 3: 格式转换

**负责人**: 后端开发  
**工具**: TypeScript 转换脚本

**转换脚本**:
```typescript
// convert-to-json.ts
function convertExcelToJSON(excelData: any[]): KnowledgeNode[] {
  return excelData.map(row => ({
    id: row['知识点 ID'],
    subject: mapSubject(row['科目']),
    stage: mapStage(row['学段']),
    grade: row['年级'],
    name: row['名称'],
    definition: row['定义'],
    // ...
  }));
}
```

#### Step 4: 质量验证

**负责人**: 内容团队 + 架构师  
**验证规则**:
- [ ] 必填字段完整
- [ ] ID 格式正确
- [ ] 关联关系存在
- [ ] 准确率≥99%

#### Step 5: 导入 Neo4j

**负责人**: 后端开发  
**工具**: Neo4j Bulk Import

**导入命令**:
```cypher
LOAD CSV WITH HEADERS FROM 'file:///knowledge-math.json' AS row
CREATE (n:Knowledge {
  id: row.id,
  subject: row.subject,
  stage: row.stage,
  grade: row.grade,
  name: row.name,
  definition: row.definition
})
```

#### Step 6: 验证测试

**负责人**: 测试工程师  
**测试内容**:
- [ ] 随机抽样 100 个知识点
- [ ] 验证字段完整性

- [ ] 验证阶段适配

## 六、导入工具选型

### 候选工具

| 工具 | 优势 | 劣势 | 选择 |
|------|------|------|------|
| Neo4j Bulk Import | 速度快，官方工具 | 需要 CSV 格式 | ✅ 首选 |
| Cypher Shell | 灵活，支持复杂逻辑 | 速度较慢 | 备选 |
| APOC 库 | 功能丰富 | 需要额外安装 | 备选 |

### 推荐方案

**Neo4j Bulk Import + 自定义转换脚本**

**理由**:
- 导入速度快 (10 万节点/分钟)
- 支持事务回滚
- 官方支持完善
