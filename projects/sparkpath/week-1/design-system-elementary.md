# SparkPath 小学阶段 UI 设计规范

**版本**: v1.0  
**适用年龄**: 9-12 岁  
**设计风格**: 明亮卡通风格  
**创建日期**: 2026-04-21

---

## 一、设计理念

### 核心原则

1. **趣味性优先** (60% 权重)
   - 色彩鲜艳活泼
   - 动画效果丰富
   - 游戏化元素融入

2. **易理解性**
   - 大按钮易点击
   - 图标直观易懂
   - 文字简洁清晰

3. **正向激励**
   - 即时成功反馈
   - 成就系统可视化
   - 鼓励性文案

## 六、阴影系统

### 阴影等级

**轻阴影** (卡片悬浮)
```css
box-shadow: 0 2px 8px rgba(0, 0, 0, 0.08);
```

**中阴影** (弹窗)
```css
box-shadow: 0 4px 16px rgba(0, 0, 0, 0.12);
```

**重阴影** (模态框)
```css
box-shadow: 0 8px 32px rgba(0, 0, 0, 0.16);
```

### 使用原则

- 阴影用于提升层次感
- 避免过度使用造成视觉负担
- 悬浮状态加深阴影

## 八、动画系统

### 动画原则

1. **活泼弹跳**
   - 使用弹性缓动函数
   - 适度夸张

2. **即时反馈**
   - 点击立即响应
   - 成功有庆祝动画

3. **引导注意力**
   - 重要元素跳动
   - 进度条流畅

### 缓动函数

**弹跳效果**
```css
transition-timing-function: cubic-bezier(0.68, -0.55, 0.265, 1.55);
```

**流畅效果**
```css
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
```

### 动画时长

| 类型 | 时长 | 使用场景 |
|------|------|---------|
| 快速 | 150ms | 按钮点击 |
| 标准 | 300ms | 页面切换 |
| 慢速 | 500ms | 庆祝动画 |

### 常用动画

**按钮点击**
```css
transform: scale(0.95);
transition: transform 0.15s ease;
```

**卡片悬浮**
```css
transform: translateY(-4px);
box-shadow: 0 4px 16px rgba(0,0,0,0.12);
transition: all 0.3s ease;
```

**成功庆祝**
```css
@keyframes celebrate {
  0% { transform: scale(1); }
  50% { transform: scale(1.2) rotate(10deg); }
  100% { transform: scale(1); }
}
```

## 十一、交互细节

### 点击反馈

- 按钮点击立即缩小 (scale 0.95)
- 伴随轻微震动反馈
- 成功有彩色纸屑动画

### 加载状态

- 使用骨架屏
- 彩色加载动画
- 避免空白等待

### 空状态

- 可爱插图
- 鼓励性文案
- 引导操作按钮

### 错误提示

- 避免红色惊吓
- 使用橙色温和提示
- 提供解决方案

---

## 十二、可访问性

### 对比度要求

- 文字与背景对比度≥4.5:1
- 大字号对比度≥3:1
- 避免纯红绿色盲不友好组合

### 点击区域

- 最小点击区域 44x44px
- 按钮之间间距≥8px
- 避免误触

### 字体大小

- 正文不小于 18px
- 支持系统字体缩放
- 避免过细字体
