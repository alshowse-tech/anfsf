# SparkPath 三阶段 UI 设计规范

**版本**: 1.0  
**创建时间**: 2026-04-22  
**设计工具**: Penpot 云 (https://design.penpot.app/)  
**适用项目**: SparkPath 自适应学习平台

---

## 📋 概述

本规范定义 SparkPath 三阶段（小学、初中、高中）的 UI 设计标准，确保：
- ✅ 年龄适配的视觉风格
- ✅ 一致的用户体验
- ✅ 无障碍设计
- ✅ 响应式布局

---

## 🎨 设计原则

### 1. 年龄适配原则

| 阶段 | 年龄段 | 设计风格 | 关键词 |
|------|--------|---------|--------|
| **小学** | 6-12 岁 | 明亮卡通 | 活泼、友好、色彩丰富 |
| **初中** | 13-15 岁 | 简洁现代 | 清爽、活力、渐变 |
| **高中** | 16-18 岁 | 深色专业 | 沉稳、高效、专注 |

### 2. 无障碍设计

- **对比度**: 至少 WCAG AA 标准 (4.5:1)
- **字体大小**: 最小 14px，支持缩放
- **色盲友好**: 不只依赖颜色传达信息
- **键盘导航**: 支持完整键盘操作

### 3. 响应式设计

- **桌面优先**: 1920×1080 → 1366×768
- **平板适配**: 1024×768, 768×1024
- **移动端**: 375×667, 414×896

## 🎨 色彩系统

### 小学阶段 (Elementary)

**主色调**: 明亮活泼

```
Primary:   #FF6B6B (珊瑚红) - 活力、热情
Secondary: #4ECDC4 (青绿色) - 清新、成长
Accent:    #FFE66D (柠檬黄) - 快乐、智慧
Success:   #95E1D3 (薄荷绿) - 成就、鼓励
Warning:   #FFD93D (向日葵黄) - 提醒、注意
Error:     #FF8C8C (柔和红) - 错误、温和
```

**渐变方案**:
```css
/* 主渐变 */
background: linear-gradient(135deg, #FF6B6B 0%, #FFD93D 100%);

/* 卡片渐变 */
card-bg: linear-gradient(180deg, #FFFFFF 0%, #F0F9FF 100%);
```

**使用场景**:
- 主按钮：Primary 色
- 成功提示：Success 色 + 动画
- 成就徽章：渐变 + 闪光效果

## 🔤 字体系统

### 字体家族

```css
/* 中文优先 */
font-family: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;

/* 英文/数字 */
font-family: 'Inter', 'Roboto', -apple-system, BlinkMacSystemFont, sans-serif;

/* 代码/公式 */
font-family: 'JetBrains Mono', 'Fira Code', 'Courier New', monospace;
```

### 字号规范

| 用途 | 小学 | 初中 | 高中 |
|------|------|------|------|
| **大标题** | 36px | 32px | 28px |
| **主标题** | 28px | 24px | 22px |
| **副标题** | 22px | 20px | 18px |
| **正文** | 18px | 16px | 15px |
| **辅助文字** | 16px | 14px | 13px |
| **按钮** | 18px | 16px | 15px |

**行高**:
- 正文：1.6
- 标题：1.3
- 代码：1.5

## 🔲 组件规范

### 按钮

#### 小学版
```
尺寸：48×48px (最小点击区域)
圆角：24px (完全圆角)
阴影：0 4px 12px rgba(255, 107, 107, 0.3)
动画：弹性效果 (cubic-bezier(0.68, -0.55, 0.265, 1.55))
图标：卡通风格，24×24px
```

#### 初中版
```
尺寸：44×44px
圆角：12px
阴影：0 2px 8px rgba(108, 99, 255, 0.2)
动画：平滑过渡 (ease-out, 0.2s)
图标：简洁线条，20×20px
```

#### 高中版
```
尺寸：40×40px
圆角：8px
阴影：0 1px 4px rgba(0, 0, 0, 0.3)
动画：快速响应 (ease, 0.15s)
图标：专业图标，18×18px
```

### 卡片

#### 小学版
```
背景：白色 + 淡彩渐变
边框：3px 圆角边框 (彩色)
阴影：0 8px 24px 柔和阴影
内边距：24px
交互：悬停放大 1.05 倍 + 彩色光晕
```

#### 初中版
```
背景：白色 / 浅灰
边框：1px 细边框
阴影：0 4px 12px 轻阴影
内边距：20px
交互：悬停上移 2px + 阴影加深
```

#### 高中版
```
背景：深色渐变
边框：1px 半透明边框
阴影：0 2px 8px 深阴影
内边距：16px
交互：悬停高亮边框 + 内容淡入
```

---

### 进度条

#### 小学版
```
高度：24px
圆角：12px
填充：渐变 + 动画 (从左到右)
颜色：彩虹渐变 (红橙黄绿青蓝紫)
装饰：完成时显示星星动画
```

#### 初中版
```
高度：16px
圆角：8px
填充：平滑渐变
颜色：Primary 色渐变
装饰：百分比显示 + 等级徽章
```

#### 高中版
```
高度：12px
圆角：6px
填充：纯色
颜色：Secondary 色
装饰：精确百分比 + 时间估算
```

## 🎭 交互规范

### 动画时长

| 类型 | 时长 | 缓动 |
|------|------|------|
| **微交互** | 150ms | ease |
| **页面切换** | 300ms | ease-in-out |
| **复杂动画** | 500ms | cubic-bezier(0.4, 0, 0.2, 1) |
| **入场动画** | 400ms | ease-out |

```

- 阴影加深
- 颜色变亮

```

#### 高中版
```
- 边框高亮
```

## ♿ 无障碍规范

### 对比度要求

| 内容类型 | 最小对比度 | 目标对比度 |
|---------|-----------|-----------|
| **正文文字** | 4.5:1 | 7:1 |
| **大文字** | 3:1 | 4.5:1 |
| **UI 组件** | 3:1 | 4.5:1 |
| **图表** | 3:1 | 4.5:1 |

### 键盘导航

```
Tab 键：顺序导航
Shift+Tab：反向导航
Enter/Space：激活按钮
Esc：关闭弹窗
Arrow Keys：列表/滑块导航
```

### 屏幕阅读器

- 所有图片添加 alt 文本
- 表单字段关联 label
- 动态内容使用 aria-live
- 跳过导航链接
