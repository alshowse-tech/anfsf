### 3.2 首选推荐：Qwen3-TTS

**GitHub**: https://github.com/QwenLM/Qwen3-TTS  
**HuggingFace**: https://huggingface.co/Qwen/Qwen3-TTS

#### 核心优势

| 优势 | 说明 |
|------|------|
| **音质优秀** | 4.5/5 分，接近阿里云 TTS |
| **延迟极低** | 97ms 流式输出 (GPU) |
| **中文优化** | 专为中文场景训练 |
| **多语言** | 支持 10+ 语言 |
| **开源免费** | Apache 2.0 许可证 |
| **情感控制** | 支持情感语调调节 |

#### 技术规格

| 指标 | 数值 |
|------|------|
| 模型大小 | 0.6B 参数 |
| 显存需求 | ~4GB (FP16) |
| 推理速度 | 97ms (GPU) / 300ms (CPU) |
| 音频长度 | 最长 30 秒/次 |
| 采样率 | 24kHz |
| 支持语言 | 中文、英语、日语、韩语等 10+ |

#### 部署方案

**方案 A: 本地 GPU 部署 (推荐)**
```bash
# 安装依赖
pip install qwen3-tts torch

# 下载模型
huggingface-cli download Qwen/Qwen3-TTS

# 运行服务
python -m qwen3_tts.server --port 8000

# 调用 API
curl http://localhost:8000/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3-tts",
    "input": "你好，SparkPath",
    "voice": "zh-CN-Xiaoxiao"
  }'
```

**硬件需求**:
- GPU: NVIDIA RTX 3060+ (12GB 显存)
- CPU: 8 核+
- 内存：16GB+
- 成本：约 ¥3,000 (一次性)

### 3.4 混合方案推荐

**最佳实践**: 阿里云 TTS (主) + 本地 TTS (备用/缓存)

```
┌─────────────────────────────────────────────────────────┐
│                    SparkPath 应用层                      │
├─────────────────────────────────────────────────────────┤
│                   TTS 路由层                             │
│   ┌─────────────────────────────────────────────────┐  │
│   │  请求分类：                                      │  │
│   │  - 常用内容 (80%) → 本地 TTS                     │  │
│   │  - 首次内容 (15%) → 阿里云 TTS + 缓存           │  │
│   │  - 高优先级 (5%) → 阿里云 TTS                   │  │
│   └─────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│                   TTS 服务层                             │
│   ┌──────────────────┐    ┌──────────────────┐        │
│   │  本地 TTS (主)    │    │  阿里云 TTS (备)  │        │
│   │  Qwen3-TTS       │    │  缓存层          │        │
│   │  延迟：97ms      │    │  命中率：80%     │        │
│   │  成本：¥0        │    │  成本：¥25,200   │        │
│   └──────────────────┘    └──────────────────┘        │
└─────────────────────────────────────────────────────────┘
```

**成本优化**:
```
原始阿里云成本：¥126,000/月
本地 TTS 处理 80%: ¥0
阿里云处理 20%: ¥25,200/月
本地运维成本：¥1,580/月

总月成本：¥26,780
节省：79%
```
