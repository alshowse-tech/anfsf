# 高中阶段 UI 原型规范

**版本**: 1.0  
**创建时间**: 2026-04-22  
**目标用户**: 16-18 岁高中生  
**设计风格**: 深色专业、沉稳高效、专注沉浸

---

## 📋 设计概述

### 核心原则

1. **效率至上**: 最大化学习效率，最小化界面干扰
2. **专业导向**: 界面设计符合学术和专业标准
3. **数据驱动**: 提供详细的学习数据分析和反馈
4. **自主掌控**: 用户完全控制学习节奏和内容
5. **深度专注**: 创造沉浸式学习环境，减少分心

### 用户特征

| 特征 | 设计响应 |
|------|---------|
| **高度自主** | 完全自定义学习路径 |
| **专业需求** | 学术级内容和工具 |
| **时间紧迫** | 高效的界面和操作 |
| **深度思考** | 支持复杂内容展示 |
| **竞争激烈** | 精确的数据对比和排名 |

**文字色**:

## 🔲 核心组件

### 1. 导航栏 (Navbar)

**位置**: 顶部固定  
**高度**: 56px  
**背景**: `#0F3460` (半透明深蓝)
**元素**:

```
[Logo] [首页] [课程] [练习] [数据分析] [个人中心]

Logo: SparkPath 极简 Logo (24×24px)
菜单项: 图标 + 文字 (18px 图标 + 15px 文字)
当前页: 底部指示条 (1px 高度, Secondary 色)
```

**交互**:
- 悬停: 颜色变亮
- 点击: 快速响应 + 页面切换

### 2. 侧边栏 (Sidebar)

**位置**: 左侧固定  
**宽度**: 240px  
**背景**: `#0D1B2A` (深海军蓝)
**触发**: 始终显示 (桌面端)

**内容**:
```
- 个人头像 (圆形, 40×40px)
- 用户名 + 年级
- 当前积分: 🌟 4580
- 等级: Lv.8 ██████████
- 快捷入口: [我的课程] [错题本] [学习分析] [竞赛]
- 设置: 齿轮图标
- 深色模式: ☀️/🌙 切换
```

### 3. 主卡片 (Main Card)

**尺寸**: 响应式 (桌面 260×180px, 移动 240×160px)  
**背景**: `#0F3460` (深蓝渐变)
**圆角**: 8px  
**阴影**: `0 2px 8px rgba(0, 0, 0, 0.4)`

**内容结构**:
```
┌─────────────────┐
│    封面图/图标   │  (64×64px)
├─────────────────┤
│    标题文字      │  (18px 加粗)
│    描述文字      │  (13px 常规)
├─────────────────┤
│   [开始按钮]     │  (40×40px 圆形)
└─────────────────┘
```

**交互**:
- 悬停: 边框高亮 + 内容淡入
- 点击: 快速响应 + 页面跳转

### 4. 进度条 (Progress Bar)

**高度**: 12px  
**圆角**: 6px  
**填充**: Secondary 色 (`#3498DB`)
**装饰**: 右侧显示精确百分比 + 时间估算

**显示内容**:
- 左侧: 课程/科目名称
- 右侧: 百分比 (如 "87.5%")
- 内部: 精确填充

### 5. 成就徽章 (Achievement Badge)

**形状**: 六边形或菱形  
**尺寸**: 40×40px  
**背景**: 深色 + 微光效  
**图标**: 极简线条风格 (奖杯、星星、火箭等)

**状态**:
- 未获得: 深灰色 + 轮廓
- 已获得: Secondary 色 + 微光效
- 新获得: 简单缩放动画

### 6. 按钮 (Button)

**主要按钮**:
- 尺寸: 40×40px (圆形) 或 90×40px (矩形)
- 背景: Secondary 色 (#3498DB)
- 文字: 白色, 15px, 加粗
- 圆角: 20px (圆形) / 6px (矩形)
- 阴影: `0 1px 4px rgba(0, 0, 0, 0.3)`

**次要按钮**:
- 尺寸: 36×36px
- 背景: 透明
- 边框: 1px Secondary 色
- 文字: Secondary 色

**交互**:
- 悬停: 颜色变亮
- 点击: 快速响应

## 🎭 交互原型

### 主要交互流程

1. **首页 → 数据驱动推荐**
   - 系统基于数据分析推荐课程
   - 动画: 数据加载 + 卡片淡入

2. **课程详情 → 深度学习**
   - 点击"继续学习" → 精确定位到上次位置
   - 动画: 快速页面切换

3. **学习 → 代码实践**
   - 理论学习后提供可运行代码环境
   - 动画: 代码编辑器滑入

4. **练习 → 数据分析**
   - 完成练习后立即更新学习数据
   - 动画: 数据图表实时更新

### 动画规范

| 动画类型 | 时长 | 缓动函数 | 触发条件 |
|---------|------|---------|---------|
| **页面切换** | 200ms | ease | 导航跳转 |
| **按钮点击** | 100ms | linear | 按钮交互 |
| **数据更新** | 300ms | ease-in-out | 数据变化 |
| **代码执行** | 150ms | ease | 代码运行 |
| **图表加载** | 400ms | ease | 图表渲染 |

## ♿ 无障碍设计

### 视觉辅助

- **字体大小**: 最小 15px
- **对比度**: 深色模式下文字与背景对比度 ≥ 4.5:1
- **高对比模式**: 可切换高对比主题
- **颜色盲友好**: 数据可视化使用图案 + 颜色

### 听觉辅助

- **屏幕阅读器**: 完整 ARIA 标签支持
- **键盘导航**: 完整键盘操作支持
- **通知系统**: 重要事件有视觉 + 听觉通知

### 操作辅助

- **点击区域**: 最小 40×40px
- **键盘快捷键**: 丰富的快捷键支持
- **代码辅助**: 代码自动补全 + 语法检查
- **公式输入**: LaTeX + 可视化公式编辑器

## 📱 响应式设计

### 断点设置

```
手机 (<768px):
  - 单列布局
  - 字体保持 15px
  - 按钮高度 40px
  - 侧边栏折叠
  
平板 (768px-1023px):
  - 双列卡片
  - 字体 15px
  - 按钮高度 40px
  - 侧边栏可展开
  
桌面 (≥1024px):
  - 三列卡片
  - 字体 15px
  - 按钮高度 40px
  - 侧边栏固定显示
```

### 触摸优化

- **触摸目标**: 最小 40×40px
- **间距**: 元素间至少 6px 间距
- **手势**: 支持滑动、双击、长按
- **反馈**: 触摸时有简洁视觉反馈
