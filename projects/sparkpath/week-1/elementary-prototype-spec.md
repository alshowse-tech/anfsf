# 小学阶段 UI 原型规范

**版本**: 1.0  
**创建时间**: 2026-04-22  
**目标用户**: 6-12 岁小学生  
**设计风格**: 明亮卡通、活泼友好、色彩丰富

---

## 📋 设计概述

### 核心原则

1. **趣味性优先**: 学习过程游戏化，增加趣味元素
2. **简单直观**: 界面元素大而清晰，操作简单
3. **视觉引导**: 使用颜色、动画引导用户注意力
4. **正向激励**: 频繁的成就反馈和鼓励机制
5. **安全友好**: 无广告、无复杂社交功能

### 用户特征

| 特征 | 设计响应 |
|------|---------|
| **注意力短** | 快速反馈 + 动画效果 |
| **阅读能力有限** | 图标 + 文字 + 语音提示 |
| **喜欢色彩** | 丰富明亮的配色方案 |
| **操作不精准** | 大点击区域 + 容错设计 |
| **需要鼓励** | 成就系统 + 正向反馈 |

## 🎨 视觉设计

### 色彩方案

**主色调**: 
- Primary: `#FF6B6B` (珊瑚红) - 活力、热情
- Secondary: `#4ECDC4` (青绿色) - 清新、成长  
- Accent: `#FFE66D` (柠檬黄) - 快乐、智慧

**背景色**:
- 主背景: `#FFFFFF` (纯白)
- 卡片背景: `linear-gradient(180deg, #FFFFFF 0%, #F0F9FF 100%)`
- 强调背景: `#FFF9E6` (淡黄色)

**文字色**:
- 主文字: `#333333` (深灰)
- 辅助文字: `#666666` (中灰)
- 强调文字: `#FF6B6B` (珊瑚红)

### 字体系统

```
字体家族: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei'
字号:
  - 大标题: 36px (加粗)
  - 主标题: 28px (加粗)  
  - 副标题: 22px (常规)
  - 正文: 18px (常规)
  - 辅助文字: 16px (常规)
  - 按钮: 18px (加粗)
行高: 1.6
```

### 图标风格

- **风格**: 卡通扁平化
- **线条**: 圆润无尖角
- **颜色**: 使用主色调
- **尺寸**: 24×24px (最小), 48×48px (主要)
- **动画**: 简单弹跳或旋转效果

## 🔲 核心组件

### 1. 导航栏 (Navbar)

**位置**: 顶部固定  
**高度**: 80px  
**背景**: 白色 + 底部阴影  
**元素**:

```
[Logo] [首页] [课程] [练习] [成就] [个人中心]

Logo: SparkPath 卡通 Logo (48×48px)
菜单项: 图标 + 文字 (24px 图标 + 18px 文字)
当前页: 底部彩色指示条 (4px 高度)
```

**交互**:
- 悬停: 轻微放大 + 彩色光晕
- 点击: 弹性动画 + 页面切换

### 2. 侧边栏 (Sidebar)

**位置**: 左侧滑出  
**宽度**: 320px  
**背景**: 白色渐变  
**触发**: 顶部汉堡菜单或手势滑动

**内容**:
```
- 个人头像 (圆形, 64×64px)
- 用户名 + 年级
- 当前积分: 🌟 1250
- 进度条: 课程完成度
- 快捷入口: [我的课程] [错题本] [好友]
- 设置: 齿轮图标
```

### 3. 主卡片 (Main Card)

**尺寸**: 响应式 (桌面 320×240px, 移动 280×200px)  
**背景**: 白色 + 淡彩渐变  
**圆角**: 24px  
**阴影**: `0 8px 24px rgba(255, 107, 107, 0.2)`

**内容结构**:
```
┌─────────────────┐
│    插图/图标     │  (120×120px)
├─────────────────┤
│    标题文字      │  (22px 加粗)
│    描述文字      │  (16px 常规)
├─────────────────┤
│   [开始按钮]     │  (48×48px 圆形)
└─────────────────┘
```

**交互**:
- 悬停: 放大 1.05 倍 + 彩色光晕
- 点击: 弹性动画 + 页面跳转

### 4. 进度条 (Progress Bar)

**高度**: 24px  
**圆角**: 12px  
**填充**: 彩虹渐变 (红→橙→黄→绿→青→蓝→紫)  
**装饰**: 完成时显示星星动画 ✨

**显示内容**:
- 左侧: 课程名称
- 右侧: 百分比 (如 "65%")
- 内部: 动态填充动画

### 5. 成就徽章 (Achievement Badge)

**形状**: 圆形或星形  
**尺寸**: 64×64px  
**背景**: 渐变 + 光效  
**图标**: 卡通风格 (奖杯、星星、火箭等)

**状态**:
- 未获得: 灰色轮廓 + 锁定图标
- 已获得: 彩色填充 + 动画效果
- 新获得: 金色闪光 + 庆祝动画

### 6. 按钮 (Button)

**主要按钮**:
- 尺寸: 48×48px (圆形) 或 120×48px (矩形)
- 背景: Primary 色 (#FF6B6B)
- 文字: 白色, 18px, 加粗
- 圆角: 24px (圆形) / 12px (矩形)
- 阴影: `0 4px 12px rgba(255, 107, 107, 0.3)`

**次要按钮**:
- 尺寸: 44×44px
- 背景: 透明
- 边框: 2px Primary 色
- 文字: Primary 色

**交互**:
- 悬停: 弹性放大 (1.1 倍)
- 点击: 压缩动画 + 反馈音效

## 🎭 交互原型

### 主要交互流程

1. **首页 → 课程选择**
   - 点击课程卡片 → 课程详情页
   - 动画: 卡片放大 + 页面滑入

2. **课程详情 → 开始学习**
   - 点击"开始学习" → 第一课
   - 动画: 按钮弹性 + 页面淡入

3. **学习 → 练习**
   - 完成学习 → 自动进入练习
   - 动画: 庆祝效果 + 进度更新

4. **练习 → 成就**
   - 获得新成就 → 弹窗通知
   - 动画: 金色闪光 + 庆祝音效

### 动画规范

| 动画类型 | 时长 | 缓动函数 | 触发条件 |
|---------|------|---------|---------|
| **页面切换** | 300ms | ease-in-out | 导航跳转 |
| **按钮点击** | 150ms | cubic-bezier(0.68, -0.55, 0.265, 1.55) | 按钮交互 |
| **卡片悬停** | 200ms | ease-out | 鼠标悬停 |
| **成就获得** | 500ms | ease | 新成就解锁 |
| **进度更新** | 800ms | linear | 进度变化 |

## ♿ 无障碍设计

### 视觉辅助

- **大字体**: 最小 18px
- **高对比**: 文字与背景对比度 ≥ 4.5:1
- **图标+文字**: 所有功能都有图标和文字说明
- **颜色盲友好**: 不只依赖颜色传达信息

### 听觉辅助

- **语音提示**: 关键操作有语音反馈
- **音效开关**: 可关闭音效
- **语速调节**: 语音速度可调节

### 操作辅助

- **大点击区域**: 最小 48×48px
- **容错设计**: 误操作可撤销
- **键盘导航**: 支持 Tab 键导航
- **手势简化**: 复杂手势有替代方案

## 📱 响应式设计

### 断点设置

```
手机 (<768px):
  - 单列布局
  - 字体缩小到 16px
  - 按钮高度 44px
  
平板 (768px-1023px):
  - 双列卡片
  - 字体保持 18px
  - 按钮高度 48px
  
桌面 (≥1024px):
  - 三列卡片
  - 字体 18px
  - 按钮高度 48px
```

### 触摸优化

- **触摸目标**: 最小 48×48px
- **间距**: 元素间至少 8px 间距
- **手势**: 支持滑动、双击、长按
- **反馈**: 触摸时有视觉反馈
