## 三、推荐方案

### 首选方案：阿里云 TTS + 本地缓存

**架构设计**:
```
┌─────────────────────────────────────────────────────────┐
│                    SparkPath 应用层                      │
├─────────────────────────────────────────────────────────┤
│                   TTS 缓存层 (Redis)                     │
│   ┌─────────────────────────────────────────────────┐  │
│   │  缓存键：text_hash + voice_id                    │  │
│   │  缓存值：audio_url + timestamps (逐词时间戳)     │  │
│   │  过期时间：7 天                                   │  │
│   └─────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────┤
│                   TTS 服务层                             │
│   ┌─────────────────────────────────────────────────┐  │
│   │  主服务：阿里云 TTS                              │  │
│   │  备用服务：百度 TTS                              │  │
│   │  降级方案：本地 TTS                              │  │
│   └─────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

**缓存策略**:
1. **常用内容预缓存**
   - 课程介绍、指令语等高频内容
   - 提前生成，直接读取

2. **实时内容缓存**
   - 首次请求调用 TTS 服务
   - 结果缓存 7 天
   - 相同内容直接返回

3. **缓存命中率预估**: 80%

**成本优化**:
```
原始月成本：¥630,000
缓存后成本：¥126,000
节省：80%
```

**延迟优化**:
```
无缓存：150ms (阿里云) + 网络传输
有缓存：20ms (Redis) + 网络传输
平均延迟：(150ms × 20%) + (20ms × 80%) = 46ms
```

### 备选方案：科大讯飞教育专用

**适用场景**:
- 对音质要求极高的场景
- 教育专用音色需求
- 预算充足情况

- [ ] 延迟测试 (目标≤200ms)
- [ ] 缓存命中率测试 (目标≥80%)

**验证代码**:
```typescript
// tts-service.ts
class TTSService {
  private cache: Redis;
  private aliyunClient: AliyunTTS;
  
  async synthesize(text: string, voiceId: string): Promise<TTSResult> {
    const cacheKey = `tts:${hash(text)}:${voiceId}`;
    
    // 1. 尝试缓存
    const cached = await this.cache.get(cacheKey);
    if (cached) {
      return cached;
    }
    
    // 2. 调用 TTS 服务
    const result = await this.aliyunClient.synthesize(text, voiceId);
    
    // 3. 缓存结果 (7 天)
    await this.cache.setex(cacheKey, 7 * 24 * 3600, result);
    
    return result;
  }
}
```

**测试场景**:
1. 单句合成延迟测试 (100 次)
2. 并发测试 (1000 并发)
3. 缓存命中率测试 (10,000 次请求)
4. 降级方案测试
