# SparkPath 产品需求文档 (PRD)

**产品名称**: SparkPath (贯穿星火)  
**版本**: v1.0 (全功能版)  
**启动日期**: 2026-04-16  
**设计风格**: Apple 风格

---

## 一、产品概述

### 核心定位
专为 9-18 岁学生打造的**AI 个人学习伙伴**，贯穿小学、初中、高中三个阶段。

### 核心价值主张
| 维度 | 目标 | 验证指标 |
|------|------|---------|
| **短期** | 成绩可见提升 | 知识掌握率提升≥30% |
| **长期** | 自主学习习惯养成 | 单次学习时长≥25 分钟，中断率≤5% |

### 差异化壁垒
1. 双引擎动态协同 + 年龄感知 Learner Model
2. 官方级内容准确性 + AI 个性化生成
3. 全生命周期知识图谱自动映射（小学→初中→高中）

---

## 二、分阶段规格

| 阶段 | 年龄 | 学习加速引擎 | 行为驱动引擎 | Learner Model 权重 |
|------|------|-------------|-------------|-------------------|
| **小学** | 9-12 岁 | 方法启蒙 + 直观理解 | 高频轻介入 (游戏化) | 趣味性 60% + 掌握度 40% |
| **初中** | 13-15 岁 | 逻辑建构 + 变式应用 | 中频适配 (情景对话) | 逻辑性 50% + 自主性 50% |
| **高中** | 16-18 岁 | 高考思维 + 解题策略 | 低频深介入 (压力缓解) | 效率 70% + 压力管理 30% |

---

## 三、教学内容架构

### 三层混合架构

```
┌─────────────────────────────────────────────────────────┐
│                    验证层 (官方闭环审核)                  │
│   准确率<99% → 回退到知识图谱原始内容                      │
├─────────────────────────────────────────────────────────┤
│                    生成层 (AI 动态内容工厂)                │
│   方法步骤 + 生活应用 + 变式练习 + 阶段适配包装            │
├─────────────────────────────────────────────────────────┤
│                    基础层 (国家课程知识图谱)               │
│   教育部课标 + 主流教材官方知识点 (JSON + Neo4j)          │
└─────────────────────────────────────────────────────────┘
```

### 更新机制
- **每日**: 官方变动同步
- **每周**: 批量验证 + 优化内容池
- **每学期**: 跨阶段映射重构 + Learner Model 迁移

---

## 四、核心功能模块

### 模块 1: Learner Model Engine
- 实时构建知识图谱 + 行为状态
- 跨阶段自动映射 + 年龄权重适配

### 模块 2: 学习加速引擎 (主引擎)
- 知识漏洞精准定位 + 最短路径规划
- 方法提炼教学 (教方法 → 灵活应用)
- 动态难度自适应

### 模块 3: 行为驱动引擎 (调节器)
- 退出风险检测 + 介入策略库
- 三阶段差异化策略

### 模块 4: Experience Generator
- 实时生成教学形式 (语音 + 逐词高亮)
- TTS 同步 ("眼睛跟着声音走")
- 三阶段界面风格动态切换

### 模块 5: Feedback & Evolution Loop
- 每节课更新 Learner Model + 双引擎 KPI 优化
- 家长周报/全生命周期报告

### 模块 6: 家长端管控仪表盘
- 学习路径、掌握报告、干预记录
- 阶段目标 + 时长上限 + 休息提醒

## 五、非功能性需求

| 指标 | 要求 |
|------|------|
| **响应时间** | ≤1.5 秒 |
| **TTS 同步延迟** | ≤200ms |
| **内容准确率** | 99.9% |
| **隐私安全** | 数据本地加密，符合教育部规范 |
| **可访问性** | 语音输入/输出，多设备无缝切换 |

## 七、Apple 设计原则

### 视觉风格
- **简洁**: 少即是多，去除冗余元素
- **优雅**: 流畅动画，细腻过渡
- **无 AI 味**: 自然交互，不刻意强调技术

### 三阶段界面
| 阶段 | 色彩 | 风格 | 交互 |
|------|------|------|------|
| **小学** | 明亮活泼 | 卡通友好 | 游戏化、大按钮 |
| **初中** | 简洁现代 | 清爽专业 | 对话式、中等密度 |
| **高中** | 深色专业 | 高效简洁 | 目标导向、信息密集 |
