## 产品简介

捷阅证券信息助手是一款面向证券从业者的智能内容分析工具，可自动解析短视频/音频链接，提取内容并生成摘要，同时识别投资风险提示标签。

### 核心价值

- ⚡ **高效**: 自动解析 + ASR 语音识别 + AI 摘要，审核时间减少 80%
- 🛡️ **合规**: 自动识别违规内容，准确率 ≥ 95%
- 💰 **经济**: 按分钟计费，成功才扣费，成本可控

### 支持平台

- 抖音 (Douyin)
- 快手 (Kuaishou)
- B 站 (Bilibili)
- 微信视频号 (WeChat Channels)

## 快速开始

### 1. 注册账号

1. 访问网站首页
2. 点击"注册"按钮
3. 输入手机号和密码
4. 完成注册

### 2. 充值

1. 登录账号
2. 进入"个人中心" → "钱包管理"
3. 选择充值金额
4. 选择支付方式（微信/支付宝）
5. 完成支付

### 3. 提交任务

1. 在首页输入视频/音频链接
2. 点击"提交分析"
3. 等待处理完成（通常 1-3 分钟）

### 4. 查看结果

1. 进入"我的任务"页面
2. 点击任务查看详情
3. 查看摘要、关键点、风险标签

## 功能使用

### 提交分析任务

**步骤**:

1. 复制视频/音频链接
2. 在首页输入框粘贴链接
3. 点击"提交分析"

**支持链接格式**:
```
https://www.douyin.com/video/7123456789
https://www.kuaishou.com/short-video/xxx
https://www.bilibili.com/video/BV1xx411c7mD
```

### 查看任务状态

任务状态说明:

| 状态 | 说明 |
|------|------|
| 待处理 | 任务已提交，等待处理 |
| 解析中 | 正在解析 URL 获取视频信息 |
| 语音识别中 | 正在提取音频并转文字 |
| 生成摘要中 | 正在生成内容摘要 |
| 已完成 | 处理完成，可查看结果 |
| 失败 | 处理失败，将退还费用 |

### 查看分析结果

**结果包含**:

1. **基本信息**: 视频标题、作者、时长
2. **关键点**: 内容要点列表
3. **摘要**: 内容概要
4. **风险标签**: 识别的风险类型

**风险等级**:

| 等级 | 颜色 | 说明 |
|------|------|------|
| 低风险 | 蓝色 | 正常内容，可放心查看 |
| 中风险 | 黄色 | 可能包含投资建议，请谨慎参考 |
| 高风险 | 橙色 | 存在夸大宣传，建议核实 |
| 严重风险 | 红色 | 涉嫌违法违规，已拦截 |

## 常见问题

### Q: 充值后余额何时到账？

A: 支付成功后余额立即到账。如超过 5 分钟未到账，请联系客服。

### Q: 任务处理失败会扣费吗？

A: 不会。只有处理成功的任务才会扣费，失败的任务将全额退款。

### Q: 如何申请退款？

A: 在"个人中心" → "钱包管理"中找到对应订单，点击"申请退款"。

### Q: 支持哪些视频平台？

A: 目前支持抖音、快手、B 站、微信视频号。其他平台正在陆续接入中。

### Q: 处理一条视频需要多长时间？

A: 通常 1-3 分钟，具体取决于视频时长和网络状况。

### Q: 如何获取发票？

A: 在"个人中心" → "钱包管理" → "充值记录"中申请电子发票。
