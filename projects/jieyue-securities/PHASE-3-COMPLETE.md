## 🔄 状态轮询

```typescript
// 5 秒自动刷新（未完成的任务）
useEffect(() => {
  loadTask()
  const interval = setInterval(() => {
    if (task && !['SUCCESS', 'FAILED'].includes(task.status)) {
      loadTask(true)
    }
  }, 5000)
  return () => clearInterval(interval)
}, [taskId])
```
