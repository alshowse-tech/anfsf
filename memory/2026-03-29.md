## ASF V4.0 v0.8.5 优化规格完成

### 核心决策

将 5 条架构优化意见转化为可落地工程规格，打包为 v0.8.5 版本里程碑。

### 交付物

1. **ChangeEvent + 图追溯边 + 热力图 blast radius**
   - 模块：Graph Kernel + Storage
   - 关键数据结构：`ChangeEvent`, `TraceEdge`
   - 关键算法：`calculateBlastRadius()` (BFS 遍历), `calculateHeatScore()`

2. **Interface Budget v2**
   - 模块：Role Engine
   - 权重矩阵：`EDGE_COST`, `CONTRACT_COST`
   - 公式：`weighted_cost = Σ(edge_cost × risk_weight) + Σ(contract_cost × risk_weight)`

3. **Contract 语义化 diff + auto-commit + semver**
   - 模块：Contract Pack + DoD Guard
   - 支持：OpenAPI, DBSchema, UIProps, EventSchema
   - 状态机：draft → approved/rejected

4. **Role KPI Dashboard**
   - 模块：Role Engine + Storage
   - 6 核心指标：Throughput, FailureRate, ReworkRate, QueuePressure, ConflictRate, DriftIndex
   - 漂移指数：`JSD(taskTypeDistribution, capabilityDistribution)`
   - KPI→动作策略：QueuePressure>1.2→Split, Drift>0.35→Reassign

5. **Propose→Approve contract gate (双门禁)**
   - 模块：Ownership Lattice + DoD Guard
   - 权限：非 Architect 只能 propose，Architect 可 approve/reject
   - 自动批准条件：仅新增 optional 字段 + 风险<20
